# Propel Software (Propel PLM)

> AI-powered product data platform for manufacturers, unifying Product Lifecycle Management (PLM),
> Quality Management (QMS), and Product Information Management (PIM) natively on the Salesforce Platform.
> The REST API (Salesforce Apex REST) exposes core PLM objects — Items, Bills of Material, Changes/ECOs,
> and Attachments — plus a bulk Import API and a read-oriented PIM API. All access uses Salesforce
> OAuth 2.0 bearer tokens and executes within the requesting user's permission scope.

## APIs
- [Propel PLM Core REST API](https://developer.propelplm.com/docs/): Items, BOM, Change, Attachment
- [Propel PIM API](https://developer.propelplm.com/docs/): products, variants, categories, channels, assets
- [Propel Import API](https://developer.propelplm.com/docs/available-apis/): bulk Items/BOMs/Manufacturer Parts
